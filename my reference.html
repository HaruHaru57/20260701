CSS

  • <style>　　CSSを使える
  • color:　　文字色を変える
  • font-size:　　文字サイズを変える
  • background-color:　　背景色を変える
  • padding:　　余白を変える
  • border:　　枠線を変える
  • border-radius:　　角を丸くする
  • cursor:　　カーソルの形を変える
  • display: flex;
    ➔ 親要素に指定することで、直下の子要素（div など）を簡単に横並びにするCSSプロパティ。
  • gap: ◯px;
    ➔ Flexboxで並んだ子要素同士の間隔（すき間）を一括で設定するプロパティ。
  • justify-content: ◯◯;
    ➔ Flexboxで横並びにした要素の「横方向の位置」を揃えるプロパティ。
    （center: 中央揃え / space-between: 両端均等配置 / flex-end: 右寄せ）
  • align-items: ◯◯;
    ➔ Flexboxで横並びにした要素の「縦方向（上下）の位置」を揃えるプロパティ。
    （center: 上下中央揃え / flex-start: 上揃え / flex-end: 下揃え）
  • 完全中央配置（縦横中央）
    ➔ 親要素に display: flex; / justify-content: center; / align-items: center; の3つを組み合わせることで、子要素を完全に中央（ど真ん中）に配置できるテクニック。
  • flex-wrap: ◯◯;
    ➔ Flexboxで要素が親の幅に入りきらなくなったときの「折り返し」を設定するプロパティ。
    （wrap: 自動で次の行へ折り返す / nowrap: 折り返さずに潰して1行に収める）
  • CSS Grid（マス目レイアウト）
    ➔ display: grid; と grid-template-columns: repeat(列数, 1fr); を使うことで、縦横きれいな格子状（表のようなレイアウト）を一瞬で作れるプロパティ。
  • レスポンシブ対応（@media）
    ➔ @media (max-width: 768px) { ... } を使うことで、スマホやタブレットなど画面幅に応じてCSS（レイアウトや色など）を自動で切り替える技術。
    ※ <meta name="viewport" content="width=device-width, initial-scale=1.0"> の記述が必須！
  • カードUIとhoverアニメーション
    ➔ transform: translateY(-5px); と transition を組み合わせることで、マウスホバー時に要素をふわっと浮かせる立体的な演出が作れる。
    ※ 親要素に overflow: hidden; を設定すると、角丸（border-radius）からはみ出る画像や背景をきれいにカットできる。
  • フォームCSSと立体配置
    ➔ フォーム要素には box-sizing: border-box; と width: 100%; を組み合わせるのが鉄則。
    ➔ margin-top: -40px; のようにマイナスの余白（ネガティブマージン）を使うと、上のエリアに要素を少し重ねて立体感を出す演出ができる！

    • 条件A && 条件B 条件Aと条件Bの両方が真の場合に真になる (かつ)

    • `文字列 ${変数名} 文字列` 例: あなたの名前は ${name} です。
      面倒な「+」での文字結合を無くすよりスマートな書き方

    • 途中にスペースや改行、: などを入れたい場合は、そのままキーボードで打ち込めばそのまま画面に表示される
    • document.getElementById("〇〇").classList.add("△△")　　idが〇〇の要素に△△というクラスを追加する

      • ➔ JavaScriptからHTML要素のCSSクラスを直接くっつけたり（add）、剥がしたり（remove）できる超重要コマンド。
      ※カッコの中のクラス名には .（ドット）は不要。
      cssをいじらず、クラスを切り替えることで、JavaScriptからHTML要素の見た目を変えられる。
    • 入力欄の要素.value
      → inputタグなどの入力フォームに、ユーザーが今まさに打ち込んでいる文字列（データ）をリアルタイムで手に入れる
  • 入力欄の要素.value = "" / 要素.focus()
    • value = ""で入力フォームの文字を空っぽにリセットできる。
    • focus()で入力欄にカーソルを自動で合体させ、ユーザーがすぐに文字を打ち込める状態にする
    • 配列名.push("追加したいデータ")
      ➔ 配列の一番最後に新しいデータを追加するコマンド
    • 配列名.length
      ➔ 配列の中に今いくつデータが入っているか（要素数）を数えて数字で返してくれる道具
    • A !== B
      ➔ 「AとBが等しくない」という意味。if (input_text !== "") と書くことで、何も入力されていない空押しバグを防ぐことができる。
    • 配列名.splice(開始位置, 個数)
      ➔ 配列の指定した位置から、指定した個数分のデータを削除するコマンド。
    • return
      ➔ 関数の処理を「ここで強制終了して中断する」コマンド。エラーやガード処理の時に使う。
    • document.createElement("タグ名")
      ➔ 指定したHTMLタグ（li や div など）をJavaScript上で新しく生成するコマンド。
    • 親要素.appendChild(追加したい要素)
      ➔ 指定した親要素（ul など）の一番最後に、作った子要素（li など）を組み込んで画面に表示させるコマンド。
    • 要素.remove()
      ➔ 指定したHTML要素を、画面（DOM）から完全に削除するコマンド。

  • JavaScriptの変数とデータ型
    ➔ const 変数名 = 値;：再代入ができない変数（基本はこちらを使用）。
    ➔ let 変数名 = 値;：後から再代入（上書き）ができる変数。
    ➔ console.log(`${変数名}`);：バックティック（`）を使うと変数を埋め込める（テンプレートリテラル）。
    ➔ typeof 値：データの種類（string, number など）を確認する。
  • 複合データ構造（配列 / オブジェクト）
    ➔ 配列 [値1, 値2]：順番（インデックス番号：0からスタート）でデータを管理する。
    ➔ オブジェクト { キー: 値 }：名前（キー）と値のセットでデータを管理する（取り出しは obj.key）。
    ➔ 配列の中にオブジェクトを入れる [{ ... }, { ... }]：実務で超頻出のデータ構造（配列[0].key でアクセス）。
  • 条件分岐（if文 / 比較演算子）
    ➔ if (条件) { ... } else if (条件) { ... } else { ... }：条件によって処理を分岐させる。
    ➔ === / !==：等しい / 等しくない（型まで厳密にチェックするためイコールは3つ書く）。
    ➔ &&（かつ）/ ||（または）：複数の条件を組み合わせる。
  • 繰り返し処理（for文 / for...of文）
    ➔ for (let i = 0; i < 回数; i++) { ... }：指定した回数だけ処理を繰り返す。
    ➔ for (const item of 配列) { ... }：配列の中身を順番に1つずつ取り出して処理する（実務で最頻出）。
  • 関数（Function / 引数 / 戻り値）
    ➔ function 関数名(引数) { 処理 return 戻り値; }：繰り返す処理を1つにまとめる構文。
    ➔ 引数（ひきすう）：関数を呼び出す際に外から渡すデータ。
    ➔ return：関数の実行結果を呼び出し元に返す（処理を終了させる）。
  • アロー関数とDOM操作の基礎
    ➔ const 関数名 = (引数) => { 処理 }：関数のモダンでシンプルな書き方（アロー関数）。
    ➔ document.querySelector("#id名")：HTML内の指定した要素をJavaScriptで取得する。
    ➔ 要素.textContent = "文字"：取得したHTML要素のテキストを書き換える。
    ➔ 要素.style.プロパティ名 = "値"：JavaScriptからCSS（見た目）を直接変更する。
  • イベント処理（addEventListener）
    ➔ 要素.addEventListener("イベント名", () => { 処理 });：ユーザーの操作（クリックなど）を検知して処理を実行する。
    ➔ "click"：ユーザーが要素をクリックした時に発生するイベント。
    ➔ DOM操作（textContent や style）と組み合わせることで、動的なWebページを作成できる。
  • フォームの値取得とclassList（クラス操作）
    ➔ input要素.value：inputタグなどの入力フォームに入力されている値を取得する。
    ➔ 要素.classList.add("クラス名")：指定したCSSクラスを追加する。
    ➔ 要素.classList.remove("クラス名")：指定したCSSクラスを削除する。
    ➔ 要素.classList.toggle("クラス名")：指定したCSSクラスの追加・削除を交互に行う（ON/OFF切り替え）。
  • DOMの動的生成と親要素への追加
    ➔ document.createElement("タグ名")：JavaScript上で新しいHTML要素（<li>など）を生成する。
    ➔ 親要素.appendChild(子要素)：作成した要素を、既存の親要素の中の一番最後に追加して画面に反映する。
    ➔ 生成した要素に対して直接 addEventListener を設定することで、動的に増えた要素にもイベントを付与できる。
  • 配列の加工と抽出（map / filter）
    ➔ 配列.map((要素) => { return 変換処理; })：配列の全要素に処理を行い、同じ件数の新しい配列を生成する。
    ➔ 配列.filter((要素) => { return 条件式; })：条件を満たす（trueになる）要素だけを取り出した新しい配列を生成する。
    ➔ 元の配列を書き換えず、新しい配列を作って返すのが大きな特徴。
  • 非同期処理（async / await）と API通信（fetch）
    ➔ fetch("URL")：外部のWeb APIへリクエストを送り、データを取得する。
    ➔ async () => { ... }：非同期処理を含む関数を定義するキーワード。
    ➔ await 処理：非同期処理（通信完了など）が終わるまで次の行の実行を待機する。
    ➔ try { ... } catch (error) { ... }：通信エラー等の失敗を安全に捕獲（キャッチ）して例外処理を行う。
  • JavaScriptのモジュール分割（ES Modules）
    ➔ export const 関数名 = () => { ... }：変数や関数を別ファイルから参照できるよう公開（エクスポート）する。
    ➔ import { 関数名 } from "./ファイル名.js"：別ファイルで公開された処理を読み込んで使用する。
    ➔ <script type="module" src="main.js"></script>：HTML側で type="module" を指定することでモジュール機能が有効化される。
  • ブラウザへのデータ保存（localStorage）
    ➔ localStorage.setItem("キー", "値")：ブラウザ内にデータを永続的に保存する（ページを閉じても消えない）。
    ➔ localStorage.getItem("キー")：保存されたデータを取得する（存在しない場合は null が返る）。
    ➔ 配列やオブジェクトを保存する際は JSON.stringify() で文字列化し、読み出す際は JSON.parse() で復元する。
  • 配列オブジェクトの永続化と画面描画（JSON.stringify / parse）
    ➔ JSON.stringify(配列)：配列やオブジェクトを localStorage に保存可能な文字列データに変換する。
    ➔ JSON.parse(文字列)：保存された文字列データを、元の配列やオブジェクトとして復元する。
    ➔ データの変更時に「ローカルストレージへの保存」と「画面の再描画（render）」を一括して行う設計が基本となる。
  • JavaScriptの総復習とWeb開発の全体像
    ➔ 変数・条件分岐・繰り返し・関数：プログラムの基本的なロジックを組み立てる土台。
    ➔ DOM操作・イベント処理・classList：HTML/CSSと連携し、動的なWebページを構築する技術。
    ➔ 配列メソッド（map/filter）・非同期処理（async/await/fetch）・LocalStorage：実務で必須となるデータ加工・API通信・データ永続化。
    ➔ モジュール分割（import/export）：コードを整理し、保守性の高い設計を実現するモダンな開発手法。
  • API通信を活用したお天気検索アプリの構築
    ➔ fetch() を連鎖させ、都市名から位置情報（緯度・経度）を取得した後に詳細データを取得するマルチステップ通信。
    ➔ 入力チェック・ローディング表示（「取得中...」）・エラーハンドリング（try/catch）を組み合わせた実用的なUI設計。
  • DOM操作によるアコーディオンUIの構築
    ➔ querySelectorAll() + forEach()：複数の要素を一括取得し、それぞれにイベントを登録する。
    ➔ element.parentElement：親要素を取得し、親に対して classList.toggle("open") を適用してCSS表示を制御する。
  • DOM操作によるモーダルUIの構築
    ➔ classList.remove("hidden") / add("hidden")：CSSの表示状態を切替えてポップアップを制御する。
    ➔ event.target：クリックされた要素を判定し、背景部分（オーバーレイ）のクリック時のみ閉じる処理を実行する。
  • DOM操作とデータ属性を用いたタブUIの構築
    ➔ element.dataset.属性名：HTMLの data-* 属性（データ属性）から値を取得する。
    ➔ 一括リセット処理：forEach() を活用して既存の選択（active クラス）をすべて解除し、選択された対象のみを有効化する。
  • DOMイベントを用いたリアルタイム入力検証（バリデーション）
    ➔ input イベント：キー入力のたびに即座に発火し、リアルタイムでエラー表示・非表示を制御する。
    ➔ event.preventDefault()：フォーム送信（submit）時に発生するブラウザの自動ページ再読み込みをキャンセルする。
  • Windowオブジェクトのスクロール監視とスムーズスクロールの実装
    ➔ window.scrollY + scroll イベント：現在のスクロール量をミリ秒単位で検知し、閾値（300pxなど）を超えた際にUIを表示する。
    ➔ window.scrollTo({ top: 0, behavior: 'smooth' })：ページ最上部へ滑らかにスクロール移動させる。
